{%- comment -%} GoatCounter analytics (https://1clarkj.goatcounter.com): no cookies, no personal data. Only included in production builds, so local previews are never counted. - Page views: counted by hand (no_onload) so the visit's source can be kept for the whole visit. A link like /?ref=rai (one ref per CV or profile) is stored in sessionStorage and sent as the referrer of every page opened in that visit, so the dashboard can show which pages the reader of one application looked at. - Events: clicks on outbound links, the CV download and email, and the first play of each video, recorded as GoatCounter events named "click: " / "video: ". - To stop counting your own visits: open https://1clarkj.github.io/#toggle-goatcounter once in each browser you use. {%- endcomment -%}
